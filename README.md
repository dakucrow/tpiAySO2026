## 📝 Descripción del Proyecto
Este trabajo práctico integrador aborda el ciclo completo de aprovisionamiento, configuración, despliegue y respaldo de un servidor Linux virtualizado (**Ubuntu Server 24.04 LTS en modo consola - CLI**) alojado en un hipervisor Tipo 2 (**Oracle VM VirtualBox**).

El objetivo principal es trasladar una aplicación defensiva en Python (`imparPar.py`), desarrollada previamente en el entorno local (Windows 11), hacia un entorno de servidor aislado, utilizando **Git/GitHub** para el control de versiones y la portabilidad del código, y aplicando **Instantáneas (Snapshots)** de VirtualBox como mecanismo de resiliencia y tolerancia a fallos.
